# vpskit

给新手用的 VPS 一键工具：装面板、搭节点、做中转、查连不上的原因，全程菜单操作，不用懂命令。

## 安装

用 root 登录服务器，粘贴这一行：

```bash
curl -fsSL https://raw.githubusercontent.com/qifeng13800-crypto/vpskit/main/vk.sh -o /root/vk.sh && bash /root/vk.sh
```

运行过一次后，以后直接输入 `vk` 就能打开菜单。

**系统要求**：Ubuntu 22 / 24 或 Debian 11 / 12，需要 root 权限。

## 第一次使用

菜单里选 **1. 新手向导**，它会带你依次完成：体检 → 设置机器类型 → 安装面板 → 建一个推荐节点。

也可以按顺序手动做：

| 步骤 | 菜单 | 说明 |
|---|---|---|
| 1 | 3. 机器类型与端口 | 普通机器选 1；NAT 机选 2 并填商家给的端口范围 |
| 2 | 4. 安装面板 | 选 s-ui 或 3x-ui，自动设置随机端口、账号、密码 |
| 3 | 5. 一键搭建节点 | 选协议，直接得到链接和二维码 |

建好的节点随时可以在 **6. 查看我的节点** 里再看。

### 支持的协议

| 面板 | 协议 | 特点 |
|---|---|---|
| s-ui | VLESS + Reality | 推荐。不需要域名和证书，走 TCP，最稳 |
| s-ui | Hysteria2 | 走 UDP，线路差时提速明显 |
| s-ui | TUIC | 走 UDP，延迟低 |
| 3x-ui | VLESS + Reality | 同上 |
| 3x-ui | Shadowsocks 2022 | 轻量，建议只放在中转后面用 |

Hysteria2 和 TUIC 用的是自签证书，客户端里要打开"允许不安全"。小火箭测 UDP 节点的延迟，需要把测速方式改成 CONNECT。

## NAT 机怎么用

NAT 机是商家只分给你一段端口的机器。

1. 菜单 **3** → 选 2，填端口范围（例如 `10000-10020`）。
2. 如果这段里有端口已经在商家后台另作他用（最常见的是 SSH 登录端口），在"已占用的端口"里填上，工具就不会再分配它。
3. 如果工具检测到的公网 IP 和你实际连接这台机器用的 IP 不一样，在"连接地址"里填你实际连接用的那个。NAT 机的入口 IP 和出口 IP 经常不同，节点链接里要用入口 IP。
4. 之后每次装面板、建节点、加转发，工具都会提示：

   ```
   NAT 机：请到商家后台添加端口映射，否则外面连不上
     外部端口 10005  →  内部端口 10005    协议: TCP    （用途: 节点 vk-vless-10005）
   ```

   照着去商家后台加映射即可。UDP 协议的节点一定要选 UDP。

## 连不上怎么办

按顺序做：

1. **菜单 9. 一键排查并修复**：先排除服务器自身的问题，能修的会自动修。
2. **菜单 8. 检测是否被墙**：输入节点端口，按提示到 itdog.cn 测一下并回答颜色，工具会直接告诉你结论：

| 结论 | 处理办法 |
|---|---|
| 端口没通到外面 | 检查商家后台的端口映射或安全组 |
| 线路正常 | 问题在客户端：更新软件、重新导入节点、检查设备时间 |
| 只有这个端口被封 | 重新建一个节点（会换新端口） |
| IP 被墙 | 走中转（见下一节），或找商家换 IP |

## 落地机被墙了，用中转救活

需要另一台国内能直连的机器当中转。

1. 在**被墙的那台**上运行菜单 8，结论页会打印本机的节点链接，复制它。
2. 在**中转机**上运行 `vk`，装好或接管 s-ui 面板。
3. 菜单 **7** → **3. 链式代理**，粘贴第 1 步的链接。
4. 工具会生成一个 `vk-chain-xxxxx` 节点。用它连接，流量就是：你 → 中转机 → 落地机 → 目标网站。

两种中转方式的区别：

| 方式 | 适合 | 说明 |
|---|---|---|
| 纯端口转发 | 专线或线路好的中转机 | 最简单、最省资源；3x-ui 和 s-ui 都能用 |
| 链式代理 | 落地机被墙 | 过境段有 Reality 伪装；仅支持 s-ui |

## Komari 探针：在一个网页上看所有机器

探针分两部分：**探针面板**只装在一台机器上，**探针客户端**装在每台要监控的机器上。

1. 选一台国内能直连的机器，运行 `vk` → **13** → **1. 安装探针面板**。
2. 工具会自动完成探针的初始化，并打印面板地址、账号和密码（不用再走网页上的安装向导）。用浏览器打开地址登录即可。
3. 接着它会问要不要把机器挂上去（以后也可以从 `vk` → **13** → **2. 添加要监控的机器** 进入）。每台机器起个名字，然后：
   - **本机**：直接装好，不用再做别的。
   - **其他机器**：工具给出一行命令，到那台机器上粘贴运行即可。
4. 添加时可以顺便填这台机器的**价格、付款周期、到期日、每月流量和重置日**，都能直接回车跳过，以后在 **13** → **3** 里修改。

工具还会自动加上 4 个**延迟检测**（到国内三个点和一个国外点，每分钟一次），新加的机器会自动启用。想加别的检测目标，到探针后台的"延迟监测"里添加。

在探针网页上能看到每台机器的：在线状态、CPU、内存、实时网速、已用流量和月流量上限、到各检测点的延迟、价格和到期剩余天数。

客户端只需要能主动连上探针面板，所以 IP 被墙的机器、NAT 机都能正常上报。

安装客户端时会问是否允许"远程控制"（网页终端、远程执行命令）。默认关闭，只上报监控数据；开启后，探针面板的账号一旦泄露，这台机器也会被控制。

## 注意事项

- **接管已有面板会重设面板的端口、账号和密码**，旧的随即作废。已有的节点不受影响。
- 一台机器只装一个面板。
- 面板没有域名时是 HTTP 明文访问，不要在公共 WiFi 下登录面板。
- 面板地址里的随机路径相当于第二道密码，不要发给别人。
- 配置保存在 `/etc/vpskit/`，备份在 `/var/backups/vpskit/`，里面含面板密码，不要外传。
